# PropertyPulse Sprint 4 — 5-minute demo script

1. Sign in as a buyer and open an existing property listing.
2. Click the contact/message seller action and show the conversation thread.
3. Open the same conversation in a second browser as the property seller.
4. Send a short message from the buyer and show it arriving in the seller session. If it does not arrive live, record it as a failed WebSocket acceptance test rather than claiming real-time success.
5. As the buyer, request a future site visit.
6. As the seller, confirm the appointment and show its status/timestamp.
7. Return to the buyer view and show the confirmed appointment.
8. If using a staff account, open the appointment metrics page and explain that time-to-appointment is measured from the conversation's first message to seller confirmation.
9. Show automated test and CI results only if the current run is green.

Avoid showing secret keys, passwords, personal data, or `.env` contents during the demonstration.
