# Welcome to EstatePulse Documentation

**EstatePulse** is a responsive web-based real estate marketplace system integrating automated property price prediction, WhatsApp-like buyer-seller messaging, site visit coordination, and deal evaluation indicators (**Buyer Barometer**).

## 🚀 Key Modules

1. **Marketplace & Listing Portal:**
   Allows property sellers to register assets with location, specifications, and asking prices. Includes proactive duplicate detection.
2. **Predictive Pricing Engine:**
   Implements Multiple Linear Regression with continuous validation against actual market levels, evaluated by MSE and $R^2$.
3. **Buyer Barometer:**
   Gives buyers an instant visual value rating based on model variance.
4. **Integrated Communication:**
   Real-time chat feed with embedded site visit appointment generator and token payment confirmation.
5. **Metric Attribution System:**
   Tracks the primary project deliverable: **Time-to-Appointment** ($\le$ 2 hours target).
